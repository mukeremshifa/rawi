# Rawi adult UAE pilot runbook

Status: ready-to-review materials only. No recruitment, learner use, feedback or
seven-day observation is claimed.

## Before inviting anyone

- Select one shared course/unit from real discovery; confirm at least eight
  reachable adult learners, source permissions and a competent subject reviewer.
- Replace or approve the provisional microeconomics pack. Every published check
  and delayed-review rubric must be signed off; record reviewer name/date/version.
- Complete operator name/contact, UAE processing/transfer decision, privacy notice,
  supported Google auth and account-plan checks in `DEPLOYMENT_RUNBOOK.md`.
- Run the integrated verification gate and one explicitly capped live AI eval.
  Review every eval response and citation rather than treating schema validity as
  educational quality.

## Learner onboarding

1. Confirm the participant is 18–24, is joining voluntarily, and uses the invited
   Google account. Explain that this is a private pilot, not a graded course tool.
2. Show the privacy notice, support contact, retention period, export/delete
   controls and the unreviewed-content label if it still applies.
3. Ask the learner to choose the shared unit, make the first attempt, use help if
   needed, practise, and complete the fresh independent check.
4. Do not coach the answer. Record observable friction and interventions in the
   checklist below. Use the in-app issue report for product problems.
5. Ask the learner to return on the displayed due date. Do not mark a return or
   delayed result before it occurs.

## Founder observation checklist

- Participant code (not name), eligibility confirmed, date/time, device/network.
- Started without intervention; point of first confusion; any reload/disconnect.
- Tutor response useful/not useful and source reference supported/unsupported.
- Practice help used; independent result; elapsed session time.
- Export/delete/support controls understandable.
- Comparison with the learner's existing tool, in the learner's own words.
- Any safety, privacy, content-correctness or accessibility issue and resolution.

## Seven-day procedure

On the due date, ask the participant to sign in without sharing the old answer.
They open **Review due** and answer the distinct delayed item unaided. Only a
correct, unaided, fresh delayed attempt counts as retained. If help is needed,
record it as assisted and teach after the attempt. Record non-return as non-return,
not as failure or retention. Follow up only through the recruitment/consent channel
the founder has separately authorized.

## Metrics review

Use the founder endpoint/export to record counts with denominators:

- invited/enrolled; activated/enrolled; completed/activated;
- returned-on-another-day/activated;
- delayed-eligible, delayed-attempted and retained/delayed-attempted;
- AI calls and provider-confirmed cost per completed loop;
- open issues by category and sessions requiring founder intervention.

Synthetic fixture runs must remain labelled synthetic. A 10–20-person pilot is a
usability and preliminary-signal exercise, not causal evidence of efficacy.
